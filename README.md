# Voluntir

Mobile app for discovering and coordinating volunteer opportunities.

## Overview

A React Native app connecting volunteers with local organizations. Browse opportunities by category, save events, track hours, and manage your volunteer activity from a single interface.

## Tech Stack

- **Mobile**: React Native + Expo
- **Language**: TypeScript
- **State**: Redux
- **Backend**: Firebase / Firestore
- **Styling**: NativeWind (Tailwind CSS)
- **Build**: EAS (Expo Application Services)

## Getting Started

```bash
pnpm install
pnpm expo start
```

## Project Structure

```
api/firestore/    # Firestore data layer
app/              # App entry and navigation config
components/       # Reusable UI components
screens/          # Screen-level components
redux/            # State management
utils/            # Shared utilities
__tests__/        # Test suite
```
